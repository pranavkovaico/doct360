
# GitHub Integration

## Overview

GitHub integration connects a GitHub repository with Document360 to synchronize Markdown documentation.

## Requirements

- A GitHub account.
- An existing GitHub repository.
- Permission to access the repository.
- Markdown files committed and pushed to the repository.

## Setup Process

1. Open Extensions in Document360.
2. Find the GitHub extension.
3. Connect your GitHub account.
4. Authorize the Document360 GitHub application.
5. Grant access to the required repositories.
6. Return to Document360.
7. Create a GitHub category.
8. Select the repository and configure the synchronization.

## How Synchronization Works

1. Create or update a Markdown file in GitHub.
2. Commit the changes.
3. Push the changes to the repository.
4. Allow Document360 to synchronize the content.
5. Verify that the content appears in the appropriate category.

## Troubleshooting

If repositories are not listed:

- Verify that the correct GitHub account is connected.
- Check whether the GitHub application has repository access.
- Confirm that the repository contains committed files.
- Recheck the selected repository permissions.
- Reconnect the integration if necessary.

## Conclusion

GitHub integration helps teams maintain documentation through version-controlled Markdown files.
